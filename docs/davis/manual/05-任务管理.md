# 05 | 任务管理

> 处理催收、续签、终止三大类任务，是合同管理的下游闭环环节。

---

## 1. 功能概述

任务由合同派发产生，一个合同可以派发多个任务。任务分配给会计处理，形成「经理派发 → 会计处理 → 经理审批」的闭环。

### 任务类型

| 类型 | 值 | 说明 |
|------|---|------|
| 催收任务 | `1` | 催促客户付款 |
| 续签任务 | `2` | 合同到期前跟进续签 |
| 终止任务 | `3` | 合作终止相关 |

### 入口

```
系统管理 → 任务管理
```

---

## 2. 列表页说明

### 表格字段

| 字段 | 说明 |
|------|------|
| 任务编号 | 系统自动生成 |
| 任务标题 | 自动格式：`催收任务: {合同名}` |
| 关联合同 | 任务来源合同，可点击跳转 |
| 任务类型 | 催收 / 续签 / 终止 |
| 优先级 | 高 / 中 / 低 |
| 原金额 | 合同原始金额（accountant/sales 显示 `***`） |
| 当前协商金额 | 会计调整后的金额（accountant/sales 显示 `***`） |
| 执行人 | 任务分配的会计 |
| 截止日期 | 任务截止时间 |
| 状态 | 待处理 / 进行中 / 待审批 / 已退回 / 已完成 |
| 创建时间 | 任务创建时间 |

### 状态标签颜色

| 状态 | 标签颜色 |
|------|----------|
| 待处理 | 灰色 |
| 进行中 | 蓝色 |
| 待审批 | 橙色 |

## 3. 会计操作流程

> 适用于 accountant 角色。

### 步骤一：开始处理

在待处理任务行点击**"开始处理"**按钮。

- 状态从 `待处理(0)` 变为 `进行中(1)`
- 执行人确认接单

### 步骤二：选择处理方式

#### 方式 A：确认收款 ✅

客户确认付款，在任务行点击**"确认收款"**：

1. 弹出对话框，输入**实际收款金额**
2. 填写**收款备注**（可选）
3. 点**确定**
4. 状态变为 `已完成(4)`
5. 系统弹出提示：是否生成续签合同？

> 选择"是" → 进入新增合同页，关联原合同作为续签

#### 方式 B：退回讲价 🔄

客户要求调整金额，点击**"退回"**：

1. 弹出对话框，填写：
   - 调整后金额（协商后的新金额）
   - 退回原因（必填）
   - 附件（可选）
2. 点**确定提交**
3. 状态变为 `待审批(2)`，等待经理处理

#### 方式 C：申请终止 🛑

客户决定终止合作，点击**"申请终止"**：

1. 弹出对话框，填写终止原因（必填）
2. 点**确定提交**
3. 状态变为 `待审批(2)`，等待经理审批

---

## 4. 经理 / 管理员操作流程

> 适用于 manager / admin 角色。

### 步骤一：处理待审批任务

进入**待审批**任务列表（筛选 `status = 待审批`）：

#### 审批讲价申请

经理看到会计退回的讲价申请：

- 查看原金额 vs 会计提议的新金额
- 选择**"同意"** 或 **"拒绝"**
  - 同意：金额更新，任务变为 `进行中(1)`，会计可继续处理
  - 拒绝：任务退回会计，状态变为 `已退回(3)`

#### 审批终止申请

经理看到会计发起的终止申请：

- 选择**"同意"** 或 **"拒绝"**
  - 同意：任务完成，合同合作关系终止
  - 拒绝：任务退回会计，状态变为 `已退回(3)`

### 步骤二：重新派发任务

当任务被会计退回讲价后，经理可修改金额后重新派发：

1. 在已退回任务行点击**"重新派发"**
2. 修改协商金额
3. 点**确定**，任务重新变为 `进行中(1)`

---

## 5. 操作历史记录

每个任务都有操作日志，记录所有状态变更：

- 任务创建
- 开始处理
- 确认收款 / 退回讲价 / 申请终止
- 经理审批（同意/拒绝）
- 重新派发

点击任务行"查看详情" → 查看完整操作流水。

## 7. 防止重复派发规则

同一合同 + 同一任务类型 + 同一执行人 的组合不允许重复派发。

系统会在派发时检查：是否存在**进行中**（`status = 1`）的同类任务，有则拒绝派发。

---

## 8. 角色权限

| 角色 | 可见范围 | 可操作 |
|------|----------|--------|
| admin | 全部任务 | 全部操作 |
| manager | 全部任务 | 审批/重新派发/审批终止 |
| accountant | 仅分配给自己的 | 开始处理/确认收款/退回讲价/申请终止 |
| sales | 无任务权限 | — |

---

## 9. 注意事项

| 现象 | 说明 |
|------|------|
| 看不到任务 | accountant 只能看到 `assigned_to` 为自己的任务；sales 看不到任务 |
| 金额显示 `***` | accountant/sales 角色按设计如此 |
| 退回讲价后无法再操作 | 需等待经理审批后才能继续 |
| 无法派发任务 | 同一合同+同类型+同执行人已存在进行中任务，需先完成或取消现有任务 |
