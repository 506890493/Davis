# 03 | 合同管理

> 系统的核心业务模块，包含代账报税合同和地址租赁合同两种类型。

---

## 1. 功能概述

### 合同类型

| 类型 | 说明 | 典型场景 |
|------|------|----------|
| **代账报税合同** | 代理记账、税务申报服务 | 客户委托代账公司处理税务 |
| **地址租赁合同** | 地址出售或出租 | 写字间、办公位出租 |

### 入口

```
系统管理 → 合同管理
```

或在首页仪表盘点击合同相关统计卡片直接跳转。

---

## 3. 新增合同

### 入口

列表页点击 **"新增"** 按钮（蓝色）。

### 必填字段

所有合同必填：

- 合同类型（代账 / 地址租赁）
- 公司名称
- 开始日期
- 结束日期
- 归属会计

代账合同额外必填：

- 收费标准
- 付款周期
- 收款日期
- 收款方式（微信 / 支付宝 / 公户转账）

地址租赁合同额外必填：

- 租赁地址（省市区选择）
- 详细地址
- 租金金额

### 操作步骤

1. 选择**合同类型**
2. 填写基本信息
3. 选择**归属会计**（下拉，仅 manager + accountant 角色用户可选）
4. 选择关联客户（下拉，支持新增客户）
5. 上传附件（可选，最多 5 个文件，支持 jpg/png/pdf/doc/docx/xls/xlsx）
6. 点**提交审批**

---

## 4. 批量导入 / 导出

### 导出

1. 在列表页设置筛选条件
2. 点**导出**按钮
3. 浏览器下载 `contract_{时间戳}.xlsx`

### 批量导入

1. 点**导入**按钮
2. 下载代账合同模板 或 地址出售合同模板
3. 按模板格式填写数据
4. 上传文件
5. 勾选"更新已有数据"可覆盖已存在记录
6. 点**开始导入**

> 模板中灰色隐藏列是另一合同类型的字段，不要填写。

## 5. 合同状态机（动态计算）

合同状态**不存库**，每天凌晨定时任务根据当前日期和合同期限重新计算。

### 计算规则

```
当前日期 < 开始日期          → 未开始
当前日期 >= 开始日期
  且当前日期 <= 结束日期 - 30天 → 进行中
  且当前日期 > 结束日期 - 30天 → 即将到期
当前日期 > 结束日期            → 已过期
```

### 注意事项

- 修改合同日期后，状态**不会立即刷新**
- 通常在当天凌晨定时任务跑完后生效
- 如急需更新状态，需联系 admin 重跑定时任务

## 6. 派发催收任务

只有**已通过**（`auditStatus = 1`）的合同可以派发任务。

### 操作步骤

1. 在已通过合同列表，点击行尾**"催收"**按钮
2. 弹出派发任务对话框：
   - 任务类型：催收任务 / 续签任务
   - 分配会计：选择执行会计
   - 截止日期：选择截止时间
   - 备注：填写说明
3. 点**确定**创建任务

> 任务标题自动生成为 `"催收任务: {合同名}"` 或 `"续签任务: {合同名}"`

---

## 7. 查看合同详情

点击列表行任意位置（或点**查看**按钮）进入详情页：

- **基础信息**：编号、名称、类型、审核状态、合同状态、期限、会计等
- **客户信息**：关联的客户名称（点击跳转客户详情）
- **代账信息 / 地址出租信息**：按类型动态显示
- **附件展示**：图片可直接预览，PDF 弹窗预览，其他格式下载
- **审批记录**：点击"审批记录"查看审批流水

---

## 8. 删除合同

1. 勾选要删除的合同（支持批量）
2. 点**删除**按钮（红色）
3. 确认删除后执行逻辑删除（数据不物理删除）

> 已在执行的合同删除需谨慎，删除后任务不受影响但合同不可恢复。

---

## 9. 角色权限

| 角色 | 可见范围 | 可操作 |
|------|----------|--------|
| admin | 全部 | 全部 |
| manager | 全部 | 新增/编辑/审批/派发/删除 |
| sales | 仅自己创建的 | 新增（审批通过前可编辑）、删除 |
| accountant | 全部（金额 `***`） | 仅查看，无编辑权限 |

---

## 10. 注意事项

| 现象 | 说明 |
|------|------|
| 金额显示 `***` | accountant/sales 角色按设计如此 |
| 合同状态不实时 | 动态计算，定时任务更新 |
| 无法删除有任务的合同 | 合同删除后任务仍存在，不建议删除进行中的合同 |
| 附件上传失败 | 文件大小上限 200MB，格式需为 jpg/png/pdf/doc/docx/xls/xlsx |
| 代账合同看不到税务类型列 | accountant/sales 角色部分字段不显示 |
