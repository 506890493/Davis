# 知识库管理操作手册

> 面向管理员（admin/manager）：如何管理知识库模块，包括新增/编辑/发布/下架文档，目录管理，回收站，版本历史等。

---

## 1. 文档生命周期（核心概念）

知识库中每篇文档有三种状态，状态决定文档的可见范围：

| 状态 | 值 | 可见范围 | 说明 |
|------|---|----------|------|
| **草稿** | `0` | 仅管理员可见 | 创作中，未发布 |
| **已发布** | `1` | **全员可见**（包括 accountant/sales） | 正式发布，门户阅读端可见 |
| **已下架** | `2` | 仅管理员可见 | 从门户消失，但仍可后台编辑 |

> ⚠️ **必须强调**：只有"已发布"的文档才会在 `全部文档` 页面或 `新员工必读` 页面展示给所有人看。新增文档默认是草稿，必须手动"发布"后才会出现在阅读端。

## 2. 目录管理（分类）

### 2.1 入口

```
系统管理 → 知识库 → 目录管理
```

### 2.2 默认分类（系统预置）

| 目录名称 | 说明 |
|----------|------|
| 系统操作手册 | Davis 系统使用手册 |
| 代账知识 | 代账业务知识 |
| 会计知识 | 财务/会计类知识 |
| 工商知识 | 公司注册/变更/注销类知识 |

### 2.3 新增目录

- **根目录**：在目录管理页点击"新增根目录"
- **子目录**：点击目录右侧的"新增"按钮

填写表单：
- **名称**（必填）：目录的显示名
- **图标**：Element UI 图标名（如 `book`、`document`、`folder`）
- **排序号**：数字小的排在前
- **是否必读**：该目录下的必读文档会在仪表盘 Banner 展示

### 2.4 编辑 / 删除目录

- **编辑**：点击"编辑"按钮，修改名称、图标、排序、是否必读
- **删除**：点击"删除"按钮，**仅当目录下无文档且无子目录时才允许删除**

> 💡 删除目录前需先清空目录下的文档。

## 3. 新增文档

### 3.1 入口

```
系统管理 → 知识库 → 文档管理 → 上传文件 / 撰写文章
```

### 3.2 两种文档类型

| 类型 | 适用场景 |
|------|----------|
| **文件型**（docType=1） | 上传 PDF / Word / Excel / 图片等附件 |
| **富文本**（docType=2） | 在线编辑图文文章（支持表格/列表/代码块） |

### 3.3 操作步骤（新增）

1. 点击 **"上传文件"** 或 **"撰写文章"** 按钮
2. 填写 **标题**（必填）
3. 选择 **目录**（必填）
4. 设置 **新员工必读** 开关（可选）
5. 填写 **标签**（逗号分隔，便于检索）
6. 填写 **摘要**（会显示在列表页）
7. 文件型：上传附件；富文本：在编辑器中写正文
8. 点击 **保存**

> 📌 保存后默认是 **草稿** 状态，需要手动"发布"后才在门户可见。

## 4. 编辑文档

### 4.1 编辑入口

在文档管理列表页，点击行尾的 **"编辑"** 按钮。

### 4.2 编辑特点

- 编辑会**自动产生新版本**（v1 → v2 → v3...）
- 旧版本完整保留，可在版本历史中查看和回滚
- 编辑后状态保持不变（草稿/已发布/已下架）

### 4.3 编辑流程

1. 找到目标文档，点击 **编辑**
2. 修改标题/目录/正文/标签/摘要
3. 点 **保存**
4. 系统提示"已保存新版本 v2"
5. 列表刷新，新版本成为"当前版本"

---

## 5. 版本历史与回滚

### 5.1 查看版本

点击文档行的 **"历史"** 按钮 → 弹出左侧时间线 + 右侧预览窗。

### 5.2 版本历史操作

| 操作 | 说明 |
|------|------|
| 查看历史版本 | 点击时间线上的某个版本 → 右侧显示该版本内容 |
| 回滚到历史版本 | 在目标版本上点击 **"回滚"** → 创建新版本（不是覆盖历史） |

> 💡 回滚采用"产生新版本"策略，保留完整历史链路，不会破坏任何已有版本记录。

## 6. 发布与下架

### 6.1 发布（草稿 → 已发布）

- 在文档行点击 **"发布"** 按钮
- 状态从 `0`（草稿）变为 `1`（已发布）
- 立即在门户的"全部文档"列表展示
- 仪表盘 Banner 也会展示（如果标记为必读）

### 6.2 下架（已发布 → 已下架）

- 在已发布文档行点击 **"下架"** 按钮
- 状态从 `1`（已发布）变为 `2`（已下架）
- 从门户消失
- 后台仍可编辑并重新发布

### 6.3 重新发布

下架后如需恢复：
1. 编辑文档（必要时修改内容）
2. 点击 **"发布"** 按钮
3. 状态重新变为已发布

> ⚠️ **重要**：只有已发布文档才在门户展示。新增文档默认是草稿状态，记得发布！

## 7. 回收站

### 7.1 删除文档

- 在文档管理列表选中目标文档
- 点击 **"删除"** 按钮（红色）
- 确认后执行软删除（进入回收站）

### 7.2 回收站规则

- 删除是**软删除**（`del_flag=1`），数据保留
- **30 天后**自动物理删除（永久清除）
- 删除后 30 天内可在回收站恢复

### 7.3 回收站操作

| 操作 | 说明 |
|------|------|
| 恢复 | 从回收站恢复（状态变为草稿），恢复后需重新发布才能在门户可见 |
| 永久删除 | 立即物理删除（不可恢复） |

## 8. 新员工必读标记

### 8.1 文档级必读

- 文档的 `is_required=1` 开关
- 已发布的必读文档会出现在 `/view/required`（新员工必读页）
- 也会在仪表盘顶部 Banner 横滚展示

### 8.2 目录级必读

- 目录的 `is_required=1` 开关
- 该目录下所有"必读"文档都会在 Banner 展示

### 8.3 运营建议

- 必读仅限核心文档，建议每个分类 1-2 篇
- 太多必读等于没必读

## 9. 常见问题（FAQ）

| 问题 | 解答 |
|------|------|
| 新增文档后门户看不到？ | 默认是草稿状态，需手动点击"发布"按钮 |
| 回收站文档消失了？ | 超过 30 天被定时任务自动物理删除 |
| 删除目录失败？ | 目录下还有文档，需先删除或移动文档到其他目录 |
| 富文本图片上传失败？ | 图片以 base64 内嵌，单张建议控制在 500KB 以内 |
| 编辑后内容没变？ | 可能是浏览器缓存，Ctrl+Shift+R 强制刷新 |
| 版本历史太多？ | 建议规范编辑习惯，不要频繁无意义保存 |
| 附件上传失败？ | 单个文件 ≤ 200MB，格式：jpg/png/pdf/doc/docx/xls/xlsx |
| 谁可以管理知识库？ | admin 和 manager（acccountant/sales 仅浏览） |
