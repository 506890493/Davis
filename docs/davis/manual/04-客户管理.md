# 04 | 客户管理

> 管理所有客户信息，支持查看每个客户关联的代账合同和地址合同。

---

## 1. 功能概述

客户是合同的主体，一个客户可以关联多条代账合同和地址合同。

### 入口

```
系统管理 → 客户管理
```

---

## 2. 客户类型

| 类型 | 值 | 说明 |
|------|---|------|
| 公司 | `1` | 有限责任公司、股份有限公司 |
| 个体户 | `2` | 个体工商户 |
| 合伙企业 | `3` | 合伙企业 |
| 民办非 | `4` | 民办非企业单位 |

---

## 3. 列表页说明

### 表格字段

| 字段 | 说明 |
|------|------|
| 客户名称 | 公司/个体户全称，可点击跳转详情 |
| 客户类型 | 公司 / 个体户 / 合伙企业 / 民办非 |
| 联系人 | 主要联系人姓名 |
| 联系电话 | 主要联系电话 |
| 邮箱 | 联系邮箱 |
| 归属销售 | 创建该客户的销售人员 |
| 状态 | 正常 / 非正常 |
| 创建时间 | 记录创建日期 |

### 行展开

点击表格行左侧 **展开按钮**，可查看该客户的：

- **代账合同列表**：所有 `contractType = 1` 的关联合同
- **地址合同列表**：所有 `contractType = 2` 的关联合同

点击合同编号可直接跳转到合同详情页。

---

## 4. 新增客户

### 入口

列表页点击 **"新增"** 按钮。

### 必填字段

- 客户名称
- 客户类型（公司/个体户/合伙企业/民办非）

### 选填字段

- 联系人
- 联系电话
- 邮箱
- 地址
- 备注

### 操作步骤

1. 填写客户名称
2. 选择客户类型
3. 填写其他信息
4. 点**确定**保存

> 新增客户后，可在该客户详情页直接新增关联合同。

---

## 5. 编辑客户

1. 在列表页点击客户名称，或点击行尾**编辑**按钮
2. 修改信息
3. 点**确定**保存

---

## 6. 删除客户

### 删除条件

- 客户**没有任何关联合同**才可删除
- 若有关联合同，系统拒绝删除并提示

### 操作步骤

1. 点击行尾**删除**按钮
2. 确认删除

> 删除前请先删除客户的关联合同，或将客户状态改为"非正常"而非物理删除。

---

## 7. 客户详情页

### 入口

点击列表中的客户名称。

### 内容结构

- **基本信息**：客户名称、类型、联系人、电话、邮箱、地址、状态等
- **代账合同 Tab**：该客户的代账合同列表
- **地址合同 Tab**：该客户的地址租赁合同列表

### 快捷操作

- 点合同编号 → 跳转合同详情
- 点**新增合同** → 进入新增合同页（自动带入客户信息）

---

## 8. 角色权限

| 角色 | 可见范围 | 可操作 |
|------|----------|--------|
| admin | 全部客户 | 新增/编辑/删除 |
| manager | 全部客户 | 新增/编辑/删除 |
| sales | 仅自己创建的 | 新增/编辑（仅自己创建的） |
| accountant | 全部（金额 `***`） | 仅查看，无编辑权限 |

---

## 9. 注意事项

| 现象 | 说明 |
|------|------|
| 找不到某客户 | 可能是 sales 角色，只能看到自己创建的客户 |
| 删除时提示有关联合同 | 需先删除该客户的全部合同，或将状态改为"非正常" |
| 客户类型显示为数字 | 不可能发生，前端已做翻译 |
