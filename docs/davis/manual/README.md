## 角色索引

| 角色 | 说明 | 可访问模块 |
|------|------|-----------|
| **admin** | 系统管理员 | 全部模块 |
| **manager** | 经理/主管 | 全部业务模块（不含系统配置） |
| **accountant** | 会计 | 任务处理、通知查看、仪表盘（部分） |
| **sales** | 销售 | 合同（仅自己创建的）、客户（仅自己创建的）、仪表盘（部分） |

详见 [11-角色权限说明](./11-角色权限说明.md)。
