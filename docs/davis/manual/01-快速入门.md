# 01 | 快速入门

> 首次使用系统？本章帮你快速上手。

---

## 1. 访问系统

### 环境说明

| 环境 | 地址 | 说明 |
|------|------|------|
| 正式环境 | `http://your-domain/` | 生产环境域名 |
| 本地开发 | `http://localhost:81` | 开发调试地址 |

### 登录账号

联系系统管理员（admin）获取账号密码。默认测试账号：

| 角色 | 账号 | 密码 |
|------|------|------|
| 管理员 | admin | 自行配置 |
| 经理 | manager | 自行配置 |
| 会计 | accountant | 自行配置 |
| 销售 | sales | 自行配置 |

> **注意**：首次登录后请修改密码。密码通过 cookie 存储登录态，不是 localStorage。

## 2. 界面导航

### 顶部导航栏

```
┌──────────────────────────────────────────────────────────┐
│ Logo  知识库学习  系统管理  ▼  搜索框  通知(3)  头像 ▼   │
└──────────────────────────────────────────────────────────┘
```

- **Logo**：点击回到首页（仪表盘）
- **知识库学习**：知识库门户首页
- **系统管理**：下拉菜单，包含合同/客户/任务/账本等业务模块
- **通知图标**：显示未读通知数量，点击进入通知中心
- **头像下拉**：个人中心、退出登录

### 左侧菜单（系统管理下拉后）

根据当前账号角色，显示以下菜单：

| 菜单 | 功能 |
|------|------|
| 合同管理 | 代账合同 + 地址租赁合同列表 |
| 客户管理 | 客户信息管理 |
| 任务管理 | 催收/续签/终止任务处理 |
| 审批管理 | 独立审批申请处理 |
| 账本模块 | 财务统计（仅 admin/manager） |
| 知识库 | 目录/文档/版本/回收站管理 |
| 系统配置 | 用户/角色/菜单/字典（仅 admin） |

## 3. 通用操作

### 表格操作

| 操作 | 说明 |
|------|------|
| 搜索 | 在输入框输入关键字，按 Enter 或点"查询" |
| 筛选 | 选择下拉条件，点"查询" |
| 重置 | 点"重置"清除所有筛选条件，恢复默认列表 |
| 翻页 | 表格底部Pagination组件，点击页码或"上下页" |
| 导出 | 点"导出"按钮，导出当前筛选条件下的Excel |
| 批量选择 | 勾选左侧复选框，支持批量删除等操作 |

### 新增操作

1. 在列表页点击**新增**按钮（蓝色）
2. 填写表单，必填字段旁有红色 `*` 标记
3. 点**确定**或**保存**提交
4. 成功后自动关闭弹窗，列表刷新

### 编辑操作

1. 在列表行点击**编辑**按钮
2. 修改表单内容
3. 点**确定**保存

### 删除操作

1. 点击**删除**按钮（红色文字）
2. 弹出确认框，显示删除对象信息
3. 点**确定**执行删除

---

## 4. 表单通用规则

### 必填字段

表单中带 **红色 `*`** 的字段为必填，不填无法提交。

### 日期选择

- 点击输入框弹出日历选择器
- 支持手动输入 `YYYY-MM-DD` 格式

### 金额输入

- 保留两位小数
- accountant/sales 角色金额字段显示 `***`，不可见也无法输入

### 附件上传

1. 点击"点击上传"按钮
2. 选择文件（支持 jpg/png/pdf/doc/docx/xls/xlsx）
3. 文件上传到服务器后，显示已上传文件名
4. 点"预览"可查看（图片）或下载（其他格式）

### 富文本编辑（撰写文章）

1. 在文档管理点击"撰写文章"
2. 在富文本编辑器中输入正文
3. 支持插入图片（base64 内嵌）
4. 点保存

## 5. 状态标签颜色速查

| 状态 | 标签颜色 |
|------|----------|
| 草稿 / 待处理 / 待审批 | 灰色 |
| 进行中 / 已发布 / 已通过 | 绿色 |

| 已过期 / 已下架 / 已驳回 / 已拒绝 | 红色 |
| 必读 ★ | 橙色边框 |

## 6. 常见问题

| 问题 | 解答 |
|------|------|
| 为什么看不到金额？ | 当前账号是 accountant 或 sales，金额按设计显示为 `***` |
| 为什么有些按钮看不到？ | 当前账号没有该操作权限，联系 admin 分配 |
| 修改数据后没生效？ | 合同状态等字段由定时任务计算，不是实时更新 |
| 怎么退出登录？ | 点右上角头像 → 退出登录 |
