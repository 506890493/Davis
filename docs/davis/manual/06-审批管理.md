# 06 | 审批管理

> 独立的合同审批模块，与任务内的审批子流程是两条独立的线。

---

## 1. 功能概述

审批管理处理**新合同、续签、变更**的申请，与任务模块中的"讲价审批"和"终止审批"是**两条独立的审批流**。

| 审批类型 | 说明 |
|----------|------|
| 新合同 | 新建代账合同或地址租赁合同后提交审批 |
| 续签 | 合同到期前申请续签 |
| 变更 | 合同内容（金额、期限等）变更后申请审批 |

### 入口

```
系统管理 → 审批管理
```

---

## 2. 列表页说明

### 表格字段

| 字段 | 说明 |
|------|------|
| 申请编号 | 系统自动生成，格式如 `APPLY{年}{流水号}` |
| 审批类型 | 新合同 / 续签 / 变更 |
| 申请人 | 提交申请的用户 |
| 关联合同 | 关联的合同编号，可点击跳转 |
| 关联任务 | 关联的任务编号（可选） |
| 申请时间 | 提交申请的时间 |
| 审批状态 | 待审批 / 已通过 / 已驳回 |
| 审批意见 | 经理/管理员填写的原因 |

---

## 3. 审批流程

### 提交申请（会计 / 销售）

1. 在合同详情页点击**提交审批**
2. 选择审批类型（新合同/续签/变更）
3. 确认提交
4. 申请进入审批管理列表，等待处理

### 审批（经理 / 管理员）

1. 进入**审批管理**列表
2. 点击申请行查看详情（申请内容快照）
3. 选择**通过**或**驳回**
   - 驳回需填写原因
4. 提交审批结果

### 审批通过后

- 合同 `audit_status` 更新为 `1`（已通过）
- 合同状态变为可计算（进入"进行中"等动态状态）

### 审批驳回后

- 合同 `audit_status` 更新为 `2`（已驳回）
- 申请人收到通知（站内信）
- 申请人修改合同后重新提交审批

---

## 4. 审批状态

| 状态 | 值 | 说明 |
|------|---|------|
| 待审批 | `0` | 等待审批 |
| 已通过 | `1` | 审批通过，合同生效 |
| 已驳回 | `2` | 审批被拒绝 |

---

## 5. 角色权限

| 角色 | 可操作 |
|------|--------|
| admin | 全部审批操作 |
| manager | 全部审批操作 |
| accountant | 提交审批申请（看任务中的审批），不能操作独立审批模块 |
| sales | 提交审批申请（自己创建的合同） |

> 独立审批模块（`/system/approval`）仅 admin / manager 可操作。accountant/sales 在任务详情页完成的审批是任务内审批，不是这个模块。

---

## 6. 注意事项

| 现象 | 说明 |
|------|------|
| 看不到审批管理菜单 | 当前账号不是 admin/manager，该菜单不显示 |
| 审批意见填写后显示在哪里 | 审批意见保存在审批记录中，可在详情页查看 |
| 审批通过后合同没变化 | 确认合同 `audit_status` 是否已更新为 `1`，如未更新请联系 admin |
