# 08 | 知识库

> 内部文档管理与学习平台，支持目录管理、文档编辑、版本历史和门户展示。

---

## 1. 功能概述

知识库为内部学习材料管理工具，管理员可以创建分类、上传文件或撰写文章，员工通过门户浏览和学习。

### 入口

```
系统管理 → 知识库
         → 文档管理
         → 目录管理
         → 回收站
```

或从顶部菜单**"知识库学习"**进入门户展示页。

---

## 2. 模块组成

```
知识库
  ├── 文档管理    # 新增/编辑/删除文档
  ├── 目录管理    # 管理分类目录树
  ├── 回收站      # 已删除文档恢复/永久删除
  └── 知识库学习（门户）  # 员工浏览界面
       ├── 分类导航
       ├── 必读 Banner
       └── 文档列表
```

---

## 3. 目录管理

### 功能说明

以树形结构管理文档分类。

### 默认分类（系统预置）

| 目录名称 | 说明 |
|----------|------|
| 系统操作手册 | Davis 系统使用手册 |
| 代账知识 | 代账业务知识 |
| 会计知识 | 财务/会计类知识 |
| 工商知识 | 公司注册/变更/注销类知识 |

### 操作

| 操作 | 说明 |
|------|------|
| 新增根目录 | 点击"新增根目录" |
| 新增子目录 | 点击目录右侧"新增"按钮 |
| 编辑目录 | 点击"编辑"，修改名称/图标/排序/是否必读 |
| 删除目录 | 点击"删除"，目录下有文档时不允许删除 |
| 设置必读 | 点击"设必读"，该目录下文档会在必读 Banner 展示 |

> 删除目录前需先清空目录下的文档。

## 4. 文档管理

### 文档类型

| 类型 | 值 | 说明 |
|------|---|------|
| 文件 | `docType = 1` | 上传文件（PDF/Word/Excel/图片等） |
| 富文本 | `docType = 2` | 在线编辑的图文文章 |

### 新增文档

#### 方式一：上传文件

1. 点击"上传文件"按钮
2. 填写标题、选择目录
3. 上传附件文件（最多 5 个）
4. 设置是否"新员工必读"
5. 点**保存**

#### 方式二：撰写文章

1. 点击"撰写文章"按钮
2. 填写标题、选择目录
3. 在富文本编辑器中编写正文（支持插入图片）
4. 设置是否"新员工必读"
5. 点**保存**

### 文档状态

| 状态 | 值 | 说明 |
|------|---|------|
| 草稿 | `0` | 未发布，仅作者可见 |
| 已发布 | `1` | 正式发布，门户可见 |
| 已下架 | `2` | 已下架，不再展示 |

> 新增文档默认是**草稿状态**，需手动**发布**后门户才可见。

### 发布 / 下架

- 草稿文档点击**"发布"**按钮 → 状态变为 `已发布`
- 已发布文档点击**"下架"**按钮 → 状态变为 `已下架`

### 版本历史

每个文档支持版本管理：

1. 点击文档行"**历史**"按钮
2. 弹出版本历史对话框
3. 左侧时间线展示所有版本
4. 点击版本可查看该版本内容
5. 如需回滚，点击版本右侧"**回滚**"按钮

> 回滚会创建新版本，不会覆盖历史版本。

## 5. 回收站

### 功能说明

存储被删除的文档，**30 天后自动物理删除**。

### 操作

| 操作 | 说明 |
|------|------|
| 恢复 | 将文档从回收站恢复（状态变为草稿），恢复后需重新发布 |
| 永久删除 | 立即物理删除（不可恢复） |

> 删除时系统会提示："删除后将进入回收站，30 天后自动清理"。

## 6. 知识库门户（员工浏览）

### 入口

顶部菜单 **"知识库学习"** 或直接访问 `/view`。

### 页面结构

```
┌─────────────────────────────────────────┐
│  必读 Banner（新员工必读文档横向滚动）   │
├───────────┬─────────────────────────────┤
│  分类导航   │  文档列表                    │
│  （树形）   │  标题/类型/摘要/发布时间    │
│           │  [查看] 按钮                 │
└───────────┴─────────────────────────────┘
```

### 操作

| 操作 | 说明 |
|------|------|
| 浏览文档 | 点击文档标题或"查看"按钮，进入详情页 |
| 切换分类 | 点击左侧目录树节点，筛选该分类下文档 |
| 查看必读 | 点击右上角"📌 新员工必读"链接，筛选必读文档 |
| 搜索文档 | 在顶部搜索框输入关键字，模糊搜索标题 |

## 7. 角色权限

| 角色 | 可见范围 | 可操作 |
|------|----------|--------|
| admin | 全部 | 全部（目录/文档/版本/回收站） |
| manager | 全部 | 全部（目录/文档/版本/回收站） |
| accountant | 门户可见 | 仅浏览，不能管理 |
| sales | 门户可见 | 仅浏览，不能管理 |

---

## 8. 注意事项

| 现象 | 说明 |
|------|------|
| 新增文档后门户看不到 | 默认是草稿状态，需点击"发布"后才在门户可见 |
| 回收站文档消失了 | 超过 30 天被定时任务自动物理删除 |
| 富文本图片上传失败 | 图片以 base64 内嵌，单张大小建议控制在 500KB 以内 |
| 删除目录失败 | 目录下还有文档，需先删除或移动文档到其他目录 |
