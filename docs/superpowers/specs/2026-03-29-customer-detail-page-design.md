# 客户详情页设计方案

## 概述

新增客户详情页，用于展示客户的详细信息和客户拥有的所有合同。

## 现状

- 客户列表页已有展开功能显示合同，但信息有限
- 客户详情需要在独立页面展示更完整的信息

## 方案设计

### 1. 路由设计

| 路径 | 组件 | 说明 |
|------|------|------|
| `/system/customer/detail/:customerId` | customer/detail | 客户详情页 |

### 2. 页面结构

```
客户详情页
├── 客户基本信息卡片
│   ├── 客户名称
│   ├── 客户类型（个人/企业）
│   ├── 联系人
│   ├── 联系电话
│   ├── 邮箱
│   ├── 地址
│   ├── 状态（正常/非正常）
│   ├── 归属销售
│   ├── 创建时间
│   └── 备注
├── 客户合同列表
│   ├── 代账合同（tabs切换）
│   │   └── 合同列表（公司名称、合同编号、金额、期限、状态）
│   └── 地址合同（tabs切换）
│       └── 合同列表（公司名称、合同编号、租金、地址、期限、状态）
└── 操作按钮
    └── 返回
```

### 3. 后端改动

#### 3.1 新增 API

`CmsCustomerController.java` 新增接口：

```java
@GetMapping("/detail/{customerId}")
public AjaxResult getDetail(@PathVariable Long customerId)
```

返回：客户信息 + 代账合同列表 + 地址合同列表

### 4. 前端改动

#### 4.1 新建页面
- `ruoyi-ui/src/views/system/customer/detail.vue`

#### 4.2 修改列表页
- 客户名称列改为可点击，跳转到详情页

## 实现步骤

1. 后端：新增客户详情接口
2. 前端：新增客户详情页面
3. 前端：修改列表页客户名称可点击
4. 测试验证
